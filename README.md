# BoltIQ Trade Official Website

Official public website for BoltIQ Trade, a risk-first trading operations command
center for MT5 execution, prop-firm governance, audit trails, research validation,
and owner monitoring.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- `/` - public positioning and platform overview
- `/risk-governance` - prop-firm and account protection posture
- `/research-validation` - offline mining, smoke, no-go, and promotion gates
- `/partners` - sanitized technical-fit pilot model
- `/investors` - investor/data-room positioning
- `/legal-disclaimer` - financial-advice and simulated-performance boundaries

## Positioning Rules

- No profit promises.
- No black-box claims.
- No public trading recommendations.
- Risk governance and auditability come before scale.
- Failed and rejected research branches remain part of the evidence trail.

## Build

```bash
npm run build
```

## Deploy

The repo is linked to Vercel. Push to `main` to trigger production deployment,
or deploy manually with the Vercel CLI when needed.
